# @mp-lb/shad

shadcn registry for MP-LB components.

## Install

```bash
pnpm dlx shadcn@latest add https://shad.mp-lb.dev/r/mdkit-editor.json
pnpm dlx shadcn@latest add https://shad.mp-lb.dev/r/structured-log-viewer.json
pnpm dlx shadcn@latest add https://shad.mp-lb.dev/r/json-viewer.json
```
