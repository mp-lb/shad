# Desktop States

```bash
pnpm dlx shadcn@latest add https://shad.mp-lb.dev/r/desktop-states.json
```

<DesktopStatesDemo />

The components provide presentation; connect their callbacks to your application or Electron kit. For an offline screen, bundle the component and assets locally so they work when the hosted frontend cannot load.

```tsx
import { AppErrorBoundary } from "@mp-lb/electron-kit/react";
import { DesktopErrorState, DesktopSignInState } from "@/components/desktop-states";

<AppErrorBoundary fallback={({ reset }) => <DesktopErrorState onRetry={reset} />}>
  <App />
</AppErrorBoundary>;

<DesktopSignInState phase="waiting" onSignIn={openBrowser} />;
```

For a failed initial Electron load, build the offline view as a local renderer
entry and include its JavaScript, CSS, and HTML in the packaged app. Pass that
local file to `recoverWindowLoad`'s `showFailure`; `DesktopOfflineState` cannot
run from the hosted app while that app is unavailable.
